# Titan1um

基于 [v86](https://github.com/copy/v86) 打造的纯前端 Windows 95 浏览器模拟器。

## 特性

- **全本地运行**：系统镜像（HDA）完全在用户浏览器内存中加载，不上传任何服务器，不依赖跨域（CORS）请求。
- **便捷镜像获取**：内置镜像获取指引，可一键前往 GitHub Release 下载 `windows95.img`。
- **ISO 转换器**：内置纯前端文件夹打包工具。可将本地的老游戏或软件文件夹（支持子目录）直接打包为 `.iso` 格式，作为虚拟 CD 挂载到 Win95 中。
- **状态保存与恢复**：支持将当前的系统运行状态导出为 `State` 文件，并在下次打开时快速恢复。
- **完全可控**：支持启动、暂停、停止、重启，并可自定义分配运行内存（建议 Win95 分配 64MB - 256MB）。

## 目录结构

- `index.html`：主入口页面，提供模拟器运行界面和控制面板。
- `downloader.html`：下载说明与文件夹转 ISO 工具。
- `libv86.js` / `v86.wasm`：v86 核心运行库。
- `seabios.bin` / `vgabios.bin`：BIOS 固件文件。

## 使用方法

1. 打开页面，点击右上角的“获取镜像 ▼”。
2. 在下方展开的面板中，前往 GitHub Release 下载 `windows95.img`。
3. 如果想要运行自定义软件/游戏：
   - 在面板中选择你的软件文件夹，点击“生成 ISO”。
   - 保存生成的 `.iso` 文件到本地。
4. 回到顶部：
   - 在 **HDA (镜像)** 处选择你下载的 `windows95.img`。
   - 在 **CD (可选)** 处选择你生成的 `.iso` 文件。
5. 点击 **启动**，即可进入 Windows 95 桌面。

> **注意**：Windows 95 具有 32 位内存溢出 Bug，请勿为其分配超过 512MB 的内存，建议保持默认的 128MB。

## 部署

这是一个纯静态项目。将所有文件推送到 GitHub 并在 Cloudflare Pages 中导入该仓库即可，无需任何构建步骤。
