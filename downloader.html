获取 Windows 95 镜像

请从 GitHub Release 页面下载镜像文件：

打开 Release 下载页 →

文件名：windows95.img，大小约 1 GB。下载完成后回到本页面，在顶部“HDA (镜像)”处选择该文件。

如果上面的链接打不开，可以直接下载附件：

直接下载 windows95.img →

文件夹转 ISO（支持子目录，在 Win95 里当 CD 用）

选择一个文件夹（会递归包含所有子目录和文件），生成一个 .iso，然后在 v86 页面里把它选为 CD。

等待选择文件夹

为什么不能在这里直接下载镜像？
GitHub Release 和 Hugging Face 的下载链接都不返回 CORS 头，浏览器里的 JavaScript 无法跨域读取。
手动下载到本地后，通过 v86 页面的文件选择框加载，完全绕开跨域限制。
